# To-Do List App — Yellow Theme

Student project built with HTML, CSS, and JavaScript.

## Features
- Add tasks with both date and time.
- Display task, date, and time together.
- Edit, complete/undo, and delete tasks.
- Save tasks in the browser using localStorage.
- Responsive design for desktop and mobile.

## Run locally
Open `index.html` in a web browser.

## Publish on GitHub Pages
Upload `index.html` and this README to your repository. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.

Tasks are stored in the current browser and do not automatically sync between devices.
